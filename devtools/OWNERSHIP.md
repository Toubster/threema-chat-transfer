## Rules for everyone

1. Use only the shared API: `tmcore.protocol` (events, `EngineError`, `critical()`, `check_cancel()`),
   `tmcore.cli.Context`/`StepResult`, `tmcore.session.Session`, `tmcore.secrets.Secrets`, `tmcore.hashing`,
   `tmcore.redact`, `tmcore.netguard`, `tmcore.guards.report`. Steps never print and never write stdout.
2. No overrides, no waivers, no `trim`, no partial payloads, no password files — not even "for tests".
3. Synthetic data only: fixtures, the fake device and the canonical example values (DESIGN §10.4). IDs start
   with `ZZ`. Run `python3 scripts/scrub_check.py` before every commit (hooks: `git config core.hooksPath scripts/hooks`).
4. No device interaction from any test or CI job; device runs are the maintainer's, on explicit go only.
5. Commit only locally. No remote, no push, no release upload without the maintainer's explicit go.
