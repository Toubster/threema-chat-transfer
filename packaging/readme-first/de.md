# {App} öffnen – zuerst lesen

{App} {version} · für Threema-Chats von Android auf das iPhone

## So öffnen Sie {App} beim ersten Mal

1. Ziehen Sie {App} in den Ordner „Programme“. Starten Sie {App} nicht direkt aus diesem Fenster.
2. Öffnen Sie {App} in „Programme“. macOS meldet: „{App}“ wurde nicht geöffnet. Klicken Sie auf **Fertig** (nicht auf „In den Papierkorb“).
3. Öffnen Sie Systemeinstellungen → Datenschutz & Sicherheit und scrollen Sie nach unten zu „Sicherheit“. Bei „{App}“ wurde blockiert … klicken Sie auf **Trotzdem öffnen**.
4. Bestätigen Sie mit **Trotzdem öffnen** und Ihrem Mac-Passwort oder Touch ID. Das ist nur beim ersten Start nötig.

Unter macOS 14 geht auch der ältere Weg: in „Programme“ mit der rechten Maustaste auf {App} klicken → „Öffnen“ → „Öffnen“.

## Warum diese Warnung?

{App} ist kostenlos und nicht bei Apple registriert (das kostet 99 USD pro Jahr). macOS kann den Hersteller deshalb nicht bestätigen. Der Quellcode liegt offen auf GitHub, und jede Version hat eine Prüfsumme.

## Wenn macOS „ist beschädigt“ meldet

Dann ist der Download kaputt. Bitte laden Sie {App} erneut und vergleichen Sie die Prüfsumme mit der Datei „SHA256SUMS“ auf der Release-Seite: {repo_url}

## Was Sie brauchen

- einen Mac mit Apple-Chip und macOS 14 oder neuer, am Netzteil
- das Android-Handy mit Threema, Ihr iPhone und ein USB-Kabel
- Ihr Threema-Safe-Passwort, den Code Ihres iPhones und das Passwort Ihres Apple Accounts
- etwa 1½ bis 3 Stunden Zeit; davon ist Ihr iPhone 30 bis 60 Minuten offline

## Beta

Versionen 0.9.x sind Betas. Auf einem echten iPhone nachgewiesen (iOS 27.0, 24A437): der Wiederherstellungs-Mechanismus (eine Test-Wiederherstellung, die nichts verändert) und der ganze Ablauf der App bis zur Übertragung. Noch nicht nachgewiesen: eine Übertragung, die die App selbst bis zum Ende ausführt. Wenn Sie jeden Tag auf Ihr iPhone angewiesen sind oder keine frische Apple-Sicherung haben, warten Sie bitte auf eine spätere Version.
